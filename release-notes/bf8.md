# Blockfield/superbwarfare-fabric bf8

## Кратко

Точечное исправление дымовой шашки M18: игрок, вернувшийся в измерение (например, после смерти и возрождения), снова видит облако дыма, которое до этого пропадало для него одного.

## Для игроков

Исправление: облако дыма M18 живёт только как клиентские частицы, выпускаемые в первые 200 тиков. Если у игрока за это время пересобирался клиентский мир (смерть → комната возрождения → возвращение), частицы для него терялись, хотя остальные игроки продолжали видеть дым. Теперь граната живёт столько же, сколько её облако, и повторно проигрывает один рассеянный залп частиц для каждого игрока, увидевшего её впервые (у возрождённого игрока новый id сущности) — так что дым снова виден всем, кто вернулся.

## Технические изменения

`M18SmokeGrenadeEntity`: время жизни сущности гранаты синхронизировано со временем жизни визуального облака; при обнаружении игрока, ранее не видевшего эту гранату (новый id после возрождения), для него отдельно проигрывается один разнесённый по времени залп частиц дыма.
