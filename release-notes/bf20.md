# Blockfield/superbwarfare-fabric bf20

## Кратко

SuperbWarfare bf20: сервер проверяет сетевые пакеты ближнего боя, огня техники, кумулятивной мины и смены скина техники (закрыты удары/выстрелы/взрывы по чужим целям с любой дистанции).

## Для игроков

Исправления: урон прикладом засчитывается только по целям в радиусе досягаемости оружия; огонь техники с тактической карты — только из техники, в которой сидит стрелок; кумулятивная мина бьёт только цель в прицеле рядом и тратится только при попадании; смена скина — только nearby-техника (закрытая — только с ключом). Честная игра не меняется: стрельба из своей техники, удары в упор и смена скина своей техники рядом работают как раньше. Остальное: сведений нет.

## Технические изменения

- Удалён LaserShootMessage (C2S-киллсвитч, который не отправлял ни один клиент): урон/цель из пакета без проверок.
- MeleeAttackMessage: только GunItem в руке, цели в entityInteractionRange + MeleeRange + 1 блок, без дублей и отправителя.
- VehicleFireMessage: shooterVehicleId принимается только для техники, в которой сидит отправитель; неизвестный weaponName отбрасывается (раньше ронял серверный тик в gunData!!).
- LungeMineAttackMessage: цель (type 0) и точка взрыва (type 1) ограничены дальностью взаимодействия (+1 блок); мина тратится только при реальном попадании.
- SetVehicleSkinMessage: требуется дальность взаимодействия и правило ключа для закрытой техники (как VehicleEntity.interact).
- pip: зависимости сборки качаются по пинам вместо вендоринга (rhino, SimpleBedrockModel); URL релизов/пинов указывают на Blockfield org.

## Обновлённые компоненты

Внешних игровых зависимостей у форка нет; изменения внутренние.
