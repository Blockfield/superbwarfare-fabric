# Blockfield/superbwarfare-fabric bf6

## Кратко

Первый релиз форка Superb Warfare для Blockfield: полный перенос мода с NeoForge на Fabric 1.21.1 через Porting Lib (событийная система, Curios → Accessories, датафайлы, сервер и клиент), два закрытых сетевых бага управления дроном и набор игровых правок брони, прицела ночного видения (ПНВ) и мелкого оружейного поведения.

## Для игроков

Безопасность: закрыты две проблемы в управлении дроном — пакеты управления не проверялись на повтор (добавлены session id и порядковый номер, защита от replay) и не проверялось, что монитор действительно принадлежит игроку, который им управляет (плюс очистка «зависшего» ввода управления при смене владельца).
Новое: свой пост-шейдер прибора ночного видения вместо ванильного эффекта `night_vision` — усиление света, засветка, зерно и виньетка только в шейдере. Бронеплиты поглощают часть урона при пробивающих попаданиях и при взрывах без установленного виновника. Пули теперь бьют механизмы Create. Удар прикладом игнорирует броню. Разбиваемое стекло включено по умолчанию. При подборе патронов учитывается их количество. У броска гранаты появилась отдельная поза бега. Поножи получили модели RU/US, наплечники дают +4 на жилетах, у шлемов появился ПНВ (тег `has_nvg`, клавиша N). Добавлен дрон-разведчик (scout drone) с обрывом связи на дистанции 150–200 блоков и переносом подвеса в NBT.
Исправления: огонь от молотова проходит сквозь бронеплиту, но всё равно расходует её запас; бронепластины не гасят урон в голову (подтверждено и для SBW, и для TaCZ); починена рука в первом лице с бронёй и падение сервера при заспавне снаряда командой `/summon`; исправлены пути и текстуры слотов аксессуаров под Accessories 1.1.0; убран мёртвый `global_loot_modifiers.json`, ссылавшийся на несуществующие модификаторы и ронявший загрузку вместе с `porting_lib_loot`.

## Технические изменения

Полный порт Superb Warfare с NeoForge на Fabric 1.21.1: Porting Lib 3.1.0-beta.90+1.21.1 для событий в духе Forge, перенесены все 90 обработчиков событий с шины NeoForge, capabilities и персистентные данные переведены с Curios на Accessories, добавлен помощник верификации API, перенесены датафайлы, выделенный сервер запускается с портированным модом, клиент доходит до главного меню и подключается к серверу, настроено dev-окружение под версии пака, сборка порта уложена в локальный бюджет памяти. В git включена сборка `simplebedrockmodel-fabric-2.5.1+mc1.21.1-bf3.jar` для CI. Сетевые пакеты управления дроном получили session id и sequence-проверку (анти-replay); отдельно добавлена проверка владения монитором и очистка устаревшего состояния ввода. Атрибут `bullet_resistance` добавлен всем живым сущностям и учитывается защитой брони. Очистка держателей ресурсов измерения на `ServerWorldEvents.UNLOAD` (утечки при выгрузке измерения). CI: публикация jar на тегах `bfN`, сборка ограничена сначала 30, затем 15 минутами, workflow на Java 21 с сохранением артефактов, `--stacktrace` в логах сборки, обновление actions до Node 24. Отдельный коммит `chore: prepare public build base (S0)` готовит репозиторий к публичному виду.

## Обновлённые компоненты

- Porting Lib: 3.1.0-beta.90+1.21.1 (событийная система для Forge-подобных хуков).
- Accessories: 1.1.0 — миграция с Curios (capabilities и персистентные данные слотов аксессуаров переведены на новый API).
- В сборку включена зависимость simplebedrockmodel-fabric 2.5.1+mc1.21.1-bf3 (используется для моделей).
  Версия самого Superb Warfare до/после в коммитах не указана — это перенос существующей кодовой базы на Fabric, а не апгрейд контента мода.

## Совместимость и необходимые действия

Мод действует на обеих сторонах: сетевые пакеты управления дроном и капабилити брони — серверная часть, ПНВ-шейдер и рендер оружия/брони — клиентская; это первый релиз линии, пин пака нужно ставить одновременно на клиенте и на сервере.
