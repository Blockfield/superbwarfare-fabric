# Blockfield/superbwarfare-fabric bf15

## Кратко

Kill feed показывает убийства дальних игроков, которых клиент ещё не отслеживал, и держит записи на экране вдвое дольше.

## Для игроков

Исправление: если нападавший или жертва были дальше дистанции отслеживания сущностей, клиент не мог определить их по id и запись об убийстве в ленте пропадала. Теперь пакет об убийстве несёт UUID и предмет-оружие напрямую, и клиент строит запись по списку игроков (tab list), даже если сущность ещё не подгружена.
Изменение поведения: записи в ленте убийств держатся на экране вдвое дольше, чем раньше.

## Технические изменения

`LivingGunKillMessage` теперь передаёт UUID участников и предмет оружия вместо id сущностей; `KillMessageOverlay` и `KillMessageHandler` строят запись по данным из tab list, если сущность не найдена по id; `LivingEventHandler` и `BeastItem` обновлены под новый формат сообщения; время показа записи в HUD увеличено вдвое.

## Обновлённые компоненты

Изменений версий зависимостей в этом промежутке нет — правка внутри самого форка (формат сетевого сообщения и HUD).

## Совместимость и необходимые действия

Меняется формат сетевого сообщения об убийстве (сервер отправляет, клиент разбирает) — клиент и сервер должны быть одной версии; пин пака нужно обновить одновременно на обеих сторонах.

## Известные проблемы

Сведений нет — в коммите промежутка открытые проблемы не упоминаются.
