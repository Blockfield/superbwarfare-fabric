# Blockfield/superbwarfare-fabric bf14

## Кратко

Громкость двигателя дрона снижена так, чтобы не упираться в порог клиппинга звука Minecraft.

## Для игроков

Исправление: громкость (gain) двигателя дрона больше не превышает порог, после которого звук в Minecraft искажается (клиппинг).

## Технические изменения

`DroneEntity`: значение усиления звука двигателя понижено ниже порога клиппинга движка.

Изменений версий зависимостей в этом промежутке нет — правка внутри самого форка.
