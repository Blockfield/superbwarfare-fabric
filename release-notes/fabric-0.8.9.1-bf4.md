# Blockfield/superbwarfare-fabric fabric-0.8.9.1-bf4

## Кратко

Ещё одна ранняя (до нумерации `bfN`) сборка форка Superb Warfare: дозавершение переноса на Fabric 1.21.1 (события, датафайлы, реестры, точки входа), плюс те же игровые правки брони/дрона/оружия, что и в предыдущей такой сборке, и первое сетевое исправление управления дроном — проверка владения монитором. Приложен jar `superbwarfare-0.8.9.1-mc1.21.1-bf4.jar`.

## Для игроков

Безопасность: закрыта проблема в управлении дроном — монитор не проверял, что он действительно принадлежит игроку, который им управляет, и мог сохранять устаревший ввод управления; теперь владение проверяется, а устаревший ввод очищается.
Новое: ПНВ реализован собственным пост-шейдером вместо ванильного эффекта `night_vision` (усиление света, засветка, зерно, виньетка); бронеплиты поглощают часть урона при пробивающих попаданиях и при взрывах без установленного виновника; дрон-разведчик (scout drone) с обрывом связи на дистанции 150–200 блоков и сохранением подвеса в NBT; поножи RU/US, наплечники +4 на жилетах, ПНВ у шлемов (тег `has_nvg`, клавиша N); атрибут `bullet_resistance` для всех живых сущностей; пули бьют механизмы Create, удар прикладом игнорирует броню, разбиваемое стекло по умолчанию, учёт количества патронов при подборе, отдельная поза бега при броске гранаты.
Исправления: огонь молотова проходит сквозь бронеплиту, но расходует её запас; бронепластины не гасят урон в голову (SBW и TaCZ); пути и текстуры слотов аксессуаров починены под Accessories 1.1.0; убран мёртвый `global_loot_modifiers.json`; рука в первом лице с бронёй и падение сервера при `/summon` снаряда починены; устранены утечки при выгрузке измерения.

## Технические изменения

Порт Superb Warfare на Fabric 1.21.1: Porting Lib 3.1.0-beta.90+1.21.1, все 90 обработчиков событий перенесены с шины NeoForge, capabilities/персистентные данные переведены с Curios на Accessories, помощник верификации API, выделенный сервер запускается с портированным модом. В git включена сборка `simplebedrockmodel-fabric-2.5.1+mc1.21.1-bf3.jar` для CI. CI: сборка на Java 21 с сохранением артефактов, `--stacktrace` в логах, лимит сборки сначала 30, затем 15 минут, обновление actions до Node 24. Сетевой пакет управления дроном получил проверку владения монитором и очистку устаревшего состояния ввода.
