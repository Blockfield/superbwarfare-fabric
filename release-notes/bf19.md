# Blockfield/superbwarfare-fabric bf19

## Кратко

Техника (Mavic, скаут-дрон, танки, вертолёты) больше не замирает на месте, когда наблюдатель отворачивает от неё камеру при включённом Entity Culling пака.

## Для игроков

Исправление: при включённом в паке отсечении по камере (Entity Culling с `tickCulling`) клиентский тик сущностей вне камеры пропускается; Superb Warfare двигает технику на клиенте только в `baseTick` (`handleClientSync`), поэтому Mavic, скаут-дрон, танк или вертолёт позади наблюдателя оставались там, где он их последний раз видел. Теперь каждая единица техники помечена как не подлежащая такому отсечению — как это уже сделано для дронов дополнения FPV — и продолжает двигаться на клиенте, даже когда не в кадре.

## Технические изменения

`VehicleEntity` (общий базовый класс техники) помечен `noCulling`, чтобы Entity Culling не пропускал его клиентский тик; аналогичный подход уже используется в дополнении sbw-drone-warfare-fabric для его дронов.

## Обновлённые компоненты

Изменений версий зависимостей в этом промежутке нет — правка внутри самого форка.

## Совместимость и необходимые действия

Правка клиентская (флаг сущности для клиентского тика/рендера); эффект проявляется только при включённом в пake Entity Culling. Пин пака стоит обновить одновременно на клиенте и на сервере, как и остальные релизы этой линии.

## Известные проблемы

Сведений нет — в коммите промежутка открытые проблемы не упоминаются.
