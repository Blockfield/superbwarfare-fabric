# Blockfield/superbwarfare-fabric bf21

## Кратко

SuperbWarfare bf21: сервер засчитывает удар прикладом по технике только с той же дистанции, с которой бьёт честный клиент.

## Для игроков

Исправлено: удар прикладом по технике больше не засчитывается дальше дистанции удара оружия. Честный удар работает как раньше: в упор и до ~3 блоков до корпуса, с любой стороны техники. Удар по быстро едущей технике может не засчитаться. Остальное: сведений нет.

## Технические изменения

- MeleeAttackMessage: цель принимается, если расстояние от глаз до хитбокса не больше `entityInteractionRange + MeleeRange + 0,5` блока.
  - Хитбокс тот же, по которому целится клиентский луч: OBB‑части (без COLLISION) у техники с collision‑OBB, AABB у остальных, с тем же `pickRadius`.
  - Раньше порог был `entityInteractionRange + MeleeRange + 1` до AABB.
- OBB.getClosestPointOBB: исправлен порядок аргументов `clamp` (вызывался `org.joml.Math.clamp(min, max, value)`), точка за положительной гранью теперь ограничивается. Других вызовов у функции нет.
- Добавлена проверка `meleeReachChecks` в `killFeedCheck`.

## Обновлённые компоненты

Внешних игровых зависимостей у форка нет; изменения внутренние.

## Совместимость и необходимые действия

Пак закрепляет jar командой `scripts/bump-fork.sh superbwarfare` (side=both). Сетевой протокол и клиентский код ближнего боя не менялись: клиент bf20 с сервером bf21 бьёт как прежде (проверено на стенде), поэтому порядок выпуска клиента и сервера не важен.

## Известные проблемы

- Удар по технике, которая быстро едет, может быть отклонён: клиент рисует её позади серверной позиции.
- В паке у удара прикладом SBW нет назначенной клавиши.
